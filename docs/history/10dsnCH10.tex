\label{Chapter::Qt User Interface and Pipeline Architecture}

This chapter presents the architecture and implementation plan for adding a Qt-based user interface to the Oscilloscope / Function Generator system. The design includes MVC-based view abstraction, two selectable user interfaces, pipeline processing for scale and shift operations, FTDI communication, and multithreaded circular buffers.
